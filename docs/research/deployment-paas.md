# PaaS and serverless platforms for a Python FastAPI app

## Summary
JobPilot's shape (one long-running FastAPI process + SQLite file on disk + an in-process scheduler that polls Gmail every few minutes) rules out every serverless product as-is: Cloud Run, AWS Lambda, Vercel, Cloudflare Workers and Deno Deploy all have ephemeral or in-memory filesystems (SQLite is lost), and none keeps a background scheduler alive without either paying for an always-allocated instance or re-architecting around an external cron + managed DB. Among container PaaS free tiers, none is fit for this app: Render Free spins down after 15 min and cannot mount disks; Koyeb Free scales to zero after 1 h idle, has no volumes and is FRA/WAS-only; Railway Free gives $1/month of usage (about 6 days of a 512 MB service); Zeabur Free auto-sleeps and is region-locked; Hugging Face now requires PRO ($9/mo) to create Docker Spaces and free hardware sleeps after 48 h; PythonAnywhere Free (since 2026-01-15) has no scheduled tasks, 100 CPU-s/day and a 1-month web-app expiry. The only always-on free tier is Northflank's Developer Sandbox (2 services, 1 database, 2 cron jobs, card on file for verification), but the free compute size and volume allowance are not documented and the smallest plan is 0.1 vCPU/256 MB. Answer to the open question: if the user wants phone/laptop access while the PC is off, a server is justified and the realistic price is ~$4-6/month, not free. Best value with a Tokyo region is Fly.io: shared-cpu-1x 512 MB in nrt is $4.05/mo plus $0.15/GB/mo for a Fly Volume; you must set auto_stop_machines = "off" (fly launch defaults to "stop") and keep min_machines_running = 1, and treat the single-host volume as fragile (daily snapshots are kept 5 days; add Litestream/rclone off-site backups). Runner-up is Railway Hobby ($5/mo including $5 of usage; ~$10/GB-month RAM, ~$0.15/GB-month volume up to 5 GB) in the Singapore Metal region; Zeabur Dev ($5/mo incl. $5 credit, memory $0.00025/GB-min, CPU free, storage $0.2/GB-mo) is a comparable Asia-based alternative but its region list could not be verified from docs. Render Starter (~$7.25/mo with disk, Singapore) and PythonAnywhere Developer ($10/mo, US/EU only, ASGI still experimental) work but cost more. If ~$5/month is not acceptable, keep JobPilot on the Windows PC and use a mesh VPN for remote access; sync simply pauses while the PC is off.

Best pick: Fly.io - one shared-cpu-1x 512MB Machine in nrt (Tokyo) at $4.05/mo plus a 1GB Fly Volume at $0.15/mo (~$4.20/mo; ~$6.20 with a dedicated IPv4). Set auto_stop_machines = "off" and min_machines_running = 1 so the in-process scheduler keeps polling Gmail; keep SQLite on the volume with daily snapshots plus Litestream/rclone off-site backups because the volume is single-host and unreplicated. Card (or $25 prepaid credits) required; no ongoing free tier.
Runner up: Railway Hobby - $5/mo including $5 of usage, ~$5-6/mo total for a 512MB always-on Docker service with a persistent volume (5GB cap) in the Singapore Metal region; simplest deploy experience but no Tokyo region and card required. Zeabur Dev ($5/mo incl. $5 credit, CPU free, memory ~$10.8/GB-mo, storage $0.2/GB-mo) is the Asia-based alternative if its dashboard shows a Tokyo/Hong Kong region.
