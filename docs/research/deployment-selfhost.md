# No-cloud options: run on the user's own hardware and reach it remotely

## Summary
Verdict for JobPilot (one user, light CPU, <1 GB SQLite, read-only Gmail + job-board polling, chat UI with mic): a server is NOT required for correctness, only for convenience. Gmail is durable: when the PC wakes, one history.list call (2 quota units) with the last historyId catches up everything, and job boards polled a few times a day just go stale while the PC is off. What you lose when the PC sleeps or is off is (a) phone access to the UI and (b) near-real-time alerts while away. Privacy is the decisive no-cloud advantage: with Tailscale the Gmail refresh token, email bodies and the SQLite file never leave the house and traffic is end-to-end WireGuard (Tailscale's servers only coordinate keys); with Cloudflare Tunnel or ngrok the token still stays home but TLS is terminated at their edge, so the provider sees the app's HTML/JSON in transit. What breaks on sleep: everything. On an S3 desktop the OS stops; on a Modern Standby (S0 Low Power Idle) laptop the network stays up but Microsoft's Desktop Activity Moderator stops all Win32 apps, so uvicorn/APScheduler freeze even though the machine looks 'connected'. Fix: `powercfg /a` to see which model you have; `powercfg /change standby-timeout-ac 0` and `powercfg /change hibernate-timeout-ac 0` (optionally `powercfg /h off`); run the app as a Windows service (WinSW, MIT) from a plain `uv` venv so it starts before logon and survives Windows Update reboots; enable Tailscale 'Run unattended'; optionally have the sync loop call SetThreadExecutionState(ES_CONTINUOUS|ES_SYSTEM_REQUIRED) via ctypes while it works. HTTPS is mandatory on the phone (getUserMedia and PWA install both require a secure context), which `tailscale serve --bg 8000` gives you for free with a Let's Encrypt cert on https://<pc>.<tailnet>.ts.net. Pricing verified 2026-09-16: Tailscale Personal is $0 forever (6 users, unlimited user devices, MagicDNS/Serve/Funnel included, no card). Cloudflare Zero Trust Free covers 50 users, $0, but requires entering payment details and a domain on Cloudflare (~$10.44/yr .com at-cost, rising to $11.15 on 2026-11-01). ngrok Free is $0 with 1 GB/month, 20k requests/month, 3 endpoints, an interstitial page, and card only for TCP. Hardware: Raspberry Pi 5 prices have risen 2.2-2.5x due to the DRAM shortage (4 GB $110, 8 GB $175, 16 GB $305 since 2026-04-01), so an Intel N100 mini PC at ~$180-200 with 16 GB/500 GB and 6-12 W idle is now the better always-on box; either costs ~¥100-300/month in electricity versus ~¥1,300-1,500/month (~$8-10) for leaving a ~60 W desktop on 24/7 at Japan's ~¥31-35/kWh, so a mini PC pays for itself in about a year versus never sleeping the main PC. Gmail near-real-time: use users.watch to a Pub/Sub topic and a PULL (StreamingPull) subscription; the subscriber initiates the connection so no public endpoint is needed, Pub/Sub's Always Free 10 GiB/month dwarfs the ~100-byte notifications, but a Google Cloud billing account must exist. Critical OAuth gotcha: leave the consent screen in 'Testing' and your refresh token dies every 7 days; set it to 'In production' (unverified is fine for personal use, 100-user cap, warning screen once).

Best pick: Keep everything on the Windows 11 PC: run the app from a plain `uv` venv as a Windows service via WinSW (starts before login, survives Windows Update reboots), set `powercfg /change standby-timeout-ac 0` and `hibernate-timeout-ac 0`, and reach it from the phone with Tailscale Personal ($0, 6 users, unlimited devices, no card) using `tailscale serve --bg 8000` for a Let's Encrypt HTTPS origin so the mic and PWA install work. Gmail token, email contents and SQLite never leave home. Add Gmail users.watch + a Pub/Sub PULL subscription ($0 within 10 GiB/month, needs a billing account) only if seconds-level latency matters; otherwise poll history.list every few minutes. Put the OAuth consent screen in 'In production' or the refresh token expires every 7 days.
Runner up: Cloudflare Tunnel + Cloudflare Access on the Zero Trust Free plan (50 users, $0, but payment details required and a domain on Cloudflare at ~$10.44/yr) when you want browser-only access without installing a VPN client, at the cost of Cloudflare terminating TLS and seeing UI traffic. If 'sync must continue while the PC is off' is a real requirement, move the identical stack to an Intel N100 mini PC (~$180-200, 16 GB/500 GB, 6-12 W idle, ~¥150-300/month electricity) rather than a Raspberry Pi 5, whose 8 GB board alone is $175 after the 2026 DRAM-driven price rises.
